# What is the default rate limit?
The default API rate limit is 100 requests per minute per IP address.

# What file formats are supported for upload?
Supported formats include PDF, DOCX, TXT, HTML, and Markdown.

# Is there a rate limit on the API?
Yes, the API has a rate limit of 30 requests per minute per user.

# What happens when I reset the index?
Resetting the index removes all indexed documents and their embeddings from the vector store.
